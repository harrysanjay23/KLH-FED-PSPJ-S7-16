67 PARKING LOT – Multi-Level Parking Lot Manager
Project Overview
67 Parking Lot is a Java mini-project that demonstrates Java programming concepts through a parking lot management application.
The project contains six individual CO programs and an integrated application that combines concepts from CO1 to CO6.

- File handling
- Object-oriented programming
Project Structure
File Description
CO1.java Variables, user input, conditional statements and fee calculation
CO2.java Menu-driven program, loops and switch statements
CO3.java Two-dimensional arrays, methods and parking slot display
CO4.java Classes, objects, constructors and exception handling
co5.java File handling, record validation, sorting and searching
co6.java ArrayList, Predicate, streams, filtering and counting
Main.java Entry point of the integrated application
MultiLevelParkingLotManager.java Integrated parking management logic
presentation/ Project PowerPoint presentation
Main Project Features
- Customer menu and admin menu
- Two parking levels with three slots per level
- Vehicle type selection
- Parking fee calculation
- Parking receipt generation
- PIN-based vehicle removal
- Parking slot status display
- Vehicle searching and sorting
- Filtering and counting vehicles
- Saving and loading parking records using a file

Requirements
- Java Development Kit (JDK)
- A terminal or command prompt, or a Java IDE such as IntelliJ IDEA, Eclipse or VS Code
How to Compile and Run the Integrated Project
Place Main.java and MultiLevelParkingLotManager.java in the same folder.
Compile:
javac Main.java MultiLevelParkingLotManager.java
Run:
java Main
The application creates or uses parking.txt for saved parking records.
How to Run the Individual CO Programs
Compile and run the desired program separately. For example:
javac CO1.java
java CO1
Repeat with the appropriate filename and class name for each CO program. Make sure the Java filename matches the public class name, if the file contains a public class.
